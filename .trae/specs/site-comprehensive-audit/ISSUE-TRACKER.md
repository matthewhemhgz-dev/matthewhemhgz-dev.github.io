3. ESC 键关闭菜单并返回触发按钮
4. 添加 `aria-expanded` 和 `aria-controls` 属性

### ISSUE-P0-005: 相关文章链接格式错误

**优先级**: P0 🔴  
**类别**: SEO & 内容问题  
**影响范围**: 博客详情页  
**文件位置**: `src/components/sections/RelatedArticles.astro`

**问题详情**:
- 中文博客详情页的相关文章链接生成双斜杠
- 实际 URL: `//blog/post-slug/` (错误)
- 应为: `/blog/post-slug/` (正确)
- 影响内部链接 SEO

**根因分析**:
```astro
<a href={`/${lang}/blog/${post.id.replace(`${lang}/`, '')}/`}>
<!-- 当 lang='zh' 时，post.id 也以 'zh/' 开头，导致双斜杠 -->
```

**修复方案**:
```astro
href={lang === 'zh' 
  ? `/blog/${post.id.replace('zh/', '')}/` 
  : `/en/blog/${post.id.replace('en/', '')}/`}
```

**工作量评估**: 0.5小时

### ISSUE-P1-010: sitemap 缺少 lastmod 时间戳

**优先级**: P1 🟡  
**类别**: SEO & 内容问题  
**影响范围**: SEO  
**文件位置**: `astro.config.mjs`

**问题详情**:
- 当前 sitemap 只有 `loc` 和 `xhtml:link`
- 缺少 `lastmod` 页面更新时间
- 缺少 `changefreq` 更新频率
- 缺少 `priority` 优先级
- 搜索引擎无法判断页面新鲜度

**修复方案**:
```javascript
sitemap({
  filter: (page) => !page.includes('/404'),
  i18n: { ... },
  changefreq: 'weekly',
  priority: 0.7,
  lastmod: new Date(),
})
```

**工作量评估**: 0.5小时
